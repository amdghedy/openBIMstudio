# Open BIM Studio — دليل المستخدم

Open BIM Studio منصة BIM تعمل داخل المتصفح. تبقى نماذجك على جهازك ما لم تختر الاتصال بخدمة سحابية. يغطي هذا الدليل سير العمل اليومي من فتح النموذج حتى تصدير الرسومات. يذكر كل قسم ما تختبره الاختبارات الآلية في متصفح حقيقي وما لا تختبره.

> **مدى الاعتماد على كل ميزة.** التطبيق قيد التطوير النشط. يصنّف فهرس النضج داخل التطبيق كل أداة: *موثّقة (verified)* أو *محدودة* أو *تجريبية* أو *مخطّط لها* أو *غير متاحة*. عبارة «اختُبر في متصفح حقيقي» تعني أن اختبارًا آليًا يشغّل الميزة في Chromium مع كل تعديل. وهذا لا يغني عن تجربتها على نماذجك أنت.

المرجع الأصلي بالإنجليزية: `docs/USER-GUIDE.md`. عند أي اختلاف تُعتمد النسخة الإنجليزية.

---

## 1. البدء

**الاستخدام عبر الإنترنت:** افتح التطبيق على open-bi-mstudio.vercel.app.

**التشغيل على جهازك** (Node.js 18 أو أحدث):

```
git clone https://github.com/amdghedy/openBIMstudio.git
cd openBIMstudio
npm install
npm run dev
```

افتح العنوان الظاهر في الطرفية (غالبًا http://localhost:3000).

### أول خمس دقائق

1. أغلق شاشة الترحيب باختيار مساحة العمل ثلاثية الأبعاد (3D).
2. حمّل نموذجًا: اسحب ملف **.ifc** إلى العرض ثلاثي الأبعاد أو اضغط **Ctrl+O**.
3. للدوران: **Shift + سحب بالزر الأيسر** (أو Shift + الزر الأوسط). للتحريك: الزر الأوسط. للتكبير: عجلة الفأرة. السحب العادي بالزر الأيسر يرسم مربع تحديد.
4. اضغط **F** لملاءمة النموذج في الشاشة و**H** للعرض الرئيسي.
5. اضغط **Ctrl+P** واكتب ما تريد («section» أو «clash» أو «sheet»). لوحة الأوامر تجد كل أمر.

### أين تجد الأشياء

| المكان | ما هو |
|---|---|
| **لوحة الأوامر (Ctrl+P)** | ابحث عن أي أمر بالاسم. أسرع طريقة للوصول إلى أي أداة. |
| **مركز أوامر BIM (Ctrl+Shift+R)** | مُشغّل لأهم سير العمل. |
| **الشريط وشريط الأدوات السفلي** | أدوات مجمّعة: إنشاء، تعديل، عرض، رسومات. |
| **قائمة File** | فتح، حفظ، استيراد، تصدير (ومنها *Views → CAD (DWG / DXF)…*). |
| **لوحتا الخصائص وشجرة النموذج** | فحص العناصر المحددة أو المحمّلة وتصفيتها. |

## 2. الفتح والحفظ والمشاريع

- **فتح ملف مدعوم:** Ctrl+O أو اسحب الملف إلى العرض ثلاثي الأبعاد. IFC 2x3 وIFC 4 هما الصيغتان الرئيسيتان؛ وهناك صيغ أخرى بنضج متفاوت (راجع `docs/COMPATIBILITY.md`).
- **مشروع جديد:** Ctrl+N. **حفظ:** Ctrl+S. **الشاشة الرئيسية:** Ctrl+H.
- تُحفظ النماذج في التخزين المحلي للمتصفح وفي ملفات المشروع. لا يُرفع شيء إلا إذا أعددت التعاون أو مزوّد ذكاء اصطناعي بنفسك.

## 3. التنقل في العرض ثلاثي الأبعاد

| الإجراء | الطريقة |
|---|---|
| الدوران | **Shift + سحب أيسر** أو Shift + سحب أوسط |
| الدوران حول المحدد | Ctrl + سحب أوسط |
| التحريك | سحب بالزر الأوسط |
| التكبير (نحو المؤشر) | عجلة الفأرة (Shift + العجلة أسرع ثلاث مرات) |
| التحديد | نقرة يسرى |
| تحديد بنافذة / بتقاطع | سحب يسار→يمين / يمين→يسار |
| القائمة السياقية | نقرة يمنى |
| ملاءمة الكل | **F** |
| التكبير على المحدد | **Ctrl+Shift+F** |
| العرض الرئيسي | **H** |
| العروض القياسية | انقر وجهًا أو حافة أو زاوية في **ViewCube** (أعلى اليمين) |
| منظور / متعامد | قائمة Home في ViewCube أو ابحث عن «Orthographic» |

**إذا كان الدوران بطيئًا في نموذج كبير** فعّل **View: Smooth navigation** (ابحث عنه في Ctrl+P). أثناء الدوران أو التحريك أو التكبير يُرسم العرض بدقة أقل ثم يعود حادًّا بعد نحو خُمس ثانية من التوقف. الخيار معطّل افتراضيًا ويُحفظ اختيارك. يتأكد اختبار المتصفح من تبديل دقة الرسم واستعادتها، لكنّ مقدار التسريع على نموذجك وبطاقتك الرسومية لم يُقَس.

### شخص مرجعي (للتحقق من المقياس)

اضغط **M** لإقامة شخص بطول 1.7 م داخل النموذج مكتوب عليه «1.70 m». في العرض ثلاثي الأبعاد العادي يقف الشخص على الأرضية في منتصف العرض ويواجه الكاميرا. في وضع المشي يوضع أمامك على بعد 2 م ويبقى مكانه أثناء مشيك، لتتحقق من ارتفاعات الأبواب وعرض الممرات والخلوص. اضغط **M** مرة أخرى لإزالته. (ينتظر المفتاح لحظة تحسبًا لأن تكتب أمرًا من حرفين مثل MV.) الشخص مجسّم بسيط بلا حركة.

**الإظهار والإخفاء:** العزل **Ctrl+I**، وإلغاء العزل **Ctrl+Shift+I**. الإخفاء والعزل وظهور الفئات في الشريط وشجرة النموذج.

## 4. وضع المشي (Walk mode)

اضغط **Ctrl+W** لدخول وضع المشي عند موضع الكاميرا واتجاهها الحاليين. تمشي بارتفاع العين (1.7 م).

| المفتاح | الإجراء |
|---|---|
| **W A S D** | للأمام، لليسار، للخلف، لليمين |
| **Shift** | الجري (نحو 9 م/ث؛ المشي العادي نحو 3.2 م/ث) |
| **Ctrl** | الانحناء (أبطأ) |
| **Space / C** | صعود / نزول عموديًا. يبقى الارتفاع الجديد ثابتًا عند ترك المفتاح (الخيار **R**، مفعّل افتراضيًا)؛ ويتوقف C عند ارتفاع الوقوف. |
| **Page Up / Page Down** | الانتقال إلى المستوى الأعلى / الأدنى |
| **عجلة الفأرة** | تغيير سرعة المشي |
| **الفأرة** | النظر حولك (يطلب المتصفح التقاط المؤشر) |
| **Esc** | الخروج والعودة إلى كاميرا الدوران |
| **L** | تثبيت ارتفاعي تشغيل/إيقاف (مفعّل افتراضيًا) |
| **R** | إبقاء الارتفاع المرفوع (Space/C) تشغيل/إيقاف |
| **N** | المشي عبر الجدران تشغيل/إيقاف |
| **M** | وضع / إزالة شخص مرجعي بطول 1.7 م |
| **P** | الشخصية البشرية (1.7 م، منظور الشخص الثالث) تشغيل/إيقاف |

**خيارات المشي** (متاحة أيضًا في Ctrl+P وتُحفظ في متصفحك):
- **تثبيت ارتفاعي (L، مفعّل افتراضيًا).** يبدأ المشي تمامًا من ارتفاع الكاميرا. إذا لم تكن هناك أرضية تحتك (مثلًا بدأت في الهواء فوق النموذج) تبقى على المستوى نفسه بدل السقوط إلى أدنى مستوى. عطّله لتسقط عبر الفتحات والفراغات كما في السابق.
- **المشي عبر الجدران (N).** لا تمنعك الجدران والعوائق؛ وتبقى الأرضيات والسلالم تحملك.
- **الشخصية البشرية (P).** تُظهر شخصية بسيطة بطول 1.7 م تقف عند قدميك وتتبعها الكاميرا من 2.6 م خلفها. الشخصية مجسّم بسيط، وكاميرا الشخص الثالث لا تتجنب الجدران خلفها.

**التصادم.** تتوقف عند الجدران وتقف على الأرضيات، بما فيها جدران وأرضيات نماذج IFC المحمّلة. أبواب IFC تُعامل كأجسام صلبة لأن النموذج يعرضها مغلقة.

**اختُبر في متصفح حقيقي:** الضغط على W نحو جدار IFC يبعد 5 م يوقفك عند وجه الجدار زائد نصف قطر الجسم دون اهتزاز وبسرعة ثابتة؛ والصعود والنزول على سلّم IFC مستقيم من خمس درجات (ارتفاع الدرجة 0.17 م) إلى بسطة؛ و Esc يعيد الكاميرا.

**لم يُختبر:** النظر بالفأرة (التقاط المؤشر لا يمكن أتمتته)، والمباني متعددة الطوابق والسلالم المنحنية، والنماذج الكبيرة، ومدى سلاسته على جهازك.

## 5. صندوق القطع (Section Box) وقطع العرض ثلاثي الأبعاد

استخدم صندوق القطع لترى داخل المبنى. يقص النموذج حسب صندوق يمكنك تغيير حجمه.

1. اضغط **Ctrl+B** (أو اختر **Section Box / Cut** من صندوق الأدوات، أو ابحث عن «Section Box» في Ctrl+P). يظهر صندوق حول النموذج بأسهم سماوية على أوجهه.
2. مرّر المؤشر فوق سهم فيتحول إلى يد. **اسحب السهم** لتحريك ذلك الوجه. يُقطع النموذج خارج الصندوق.
3. استخدم الأوامر **Section Box: Grow** و**Shrink** و**Reset** (Ctrl+P) لضبط الصندوق كاملًا.
4. اضغط **Ctrl+B** مرة أخرى لإيقاف الصندوق، فيظهر النموذج كله.

**اختُبر في متصفح حقيقي:** الصندوق يقص جدار IFC محمّلًا؛ تصغير الصندوق إلى النصف يزيل نصف الجدار من الصورة؛ سحب سهم بفأرة حقيقية يحرّك ذلك الوجه ويترك الكاميرا حرّة بعده؛ التعديل لا يترك مستويات قص زائدة، وإيقافه يزيلها كلها.

**حدود معروفة:**
- أوجه القطع تُغطّى بوجه مهشّر على عناصر IFC والعناصر المنشأة داخل التطبيق (التبديل: «Section cut caps» في Ctrl+P). المواد الشفافة لا تُغطّى.
- مستويات أداة **Section** المنفصلة مختبرة في متصفح لمستوى أفقي واحد على جدار IFC (قطع، إيقاف، حذف)؛ أما سحبها والمستويات المائلة فلا.
- القطع على النماذج الكبيرة جدًا والنماذج متعددة المستويات لم يُقَس.

## 6. القياس والأبعاد ثلاثية الأبعاد

افتح أداة **Measure** (الشريط أو صندوق الأدوات أو Ctrl+P ← «Measure») واختر نمطًا:

| النمط | ما تنقر عليه | النتيجة |
|---|---|---|
| Distance | نقطتان | المسافة بينهما |
| XYZ | نقطتان | مركّبات X وY وZ والمجموع |
| Angle | ثلاث نقاط (الرأس هو الأوسط) | الزاوية |
| Chain | سلسلة نقاط | كل قطعة ومجموع متراكم |

- الأبعاد المنتهية **تبقى على الشاشة**. ارسم منها ما تشاء.
- **Esc** يلغي البعد الذي ترسمه ويزيل علامة النقطة الأولى وينهي أمر الأبعاد بضغطة واحدة. لا يحذف Esc الأبعاد المنتهية.
- **Delete** أو **Backspace** يزيل آخر بعد منتهٍ؛ اضغط مرة أخرى لإزالة الذي قبله.
- **Clear measurements** (الشريط أو لوحة Measure) يحذف كل الأبعاد.

**اختُبر في متصفح حقيقي** بنقرات حقيقية: المسافة وXYZ والزاوية والسلسلة؛ Esc أثناء كل منها؛ Clear. **لم يُختبر:** الالتقاط إلى زوايا النموذج وحوافه، وإلغاء البعد أثناء السحب.

## 7. إنشاء العناصر وتعديلها

### اختصارات الأدوات السريعة

اكتب الحرفين بالتتابع (وليس معًا):

| المفاتيح | الأداة | المفاتيح | الأداة |
|---|---|---|---|
| **WA** | جدار | **DR** | باب |
| **SL** | بلاطة | **WN** | نافذة |
| **CM** | عمود | **DU** | مجرى هواء |
| **BM** | كمرة | **PP** | ماسورة |
| **BR** | تكتيف | **GR** | شبكة محاور |
| **TR** | جمالون | **LV** | مستوى |
| **FT** | قاعدة | | |

**Esc** يلغي الأداة النشطة، و**Delete** يحذف المحدد.

### خطوط مرجعية أثناء النمذجة

عند رسم جدار (أو عارضة أو أنبوب أو غيرها من العناصر الخطية) تظهر خطوط متقطعة طويلة تمر بكل ركن في سلسلة الجدران التي ترسمها، وينجذب المؤشر إليها. عند اقتراب المؤشر من نقطة تقاطع خطين يلتصق بها، فيُغلق الجدار الأخير على الغرفة بزاوية قائمة مع الجدار الأول. لإيقافها أو تشغيلها ابحث عن «Reference lines while modelling» في Ctrl+P (يُحفظ اختيارك). **حدود:** تُستخدم فقط أركان سلسلة الجدران الجارية، لا جدران رُسمت سابقًا؛ والخطوط على المحورين X وZ فقط؛ ومسافة الالتقاط ثابتة 0.35 م. Shift وAccuDraw يتجاوزانها. اختُبرت حالة الغرفة في متصفح حقيقي، ولم يُجرَّب إحساس الفأرة على نموذج كبير.

### الدقة

- **Shift+S** يبدّل الالتقاط (snapping).
- **Tab** و**X / Y / Z** يقفلان المحاور (AccuDraw) عند وجود نقطة أساس.
- **G / R / S** يبدّلان أداة التحويل إلى نقل ودوران وتحجيم. **Q** يعود إلى التحديد.

### التعديل بالمقابض (Grips)

حدّد عنصرًا لترى **مقابضه البرتقالية**. مرّر المؤشر فوق مقبض فيتحول إلى يد، واسحبه لتغيير شكل العنصر (طرف جدار، زاوية بلاطة، حافة). يعمل الالتقاط أثناء السحب.

**اختُبر في متصفح حقيقي:** مؤشر التمرير والسحب على مقبض بلاطة. **لم يُختبر:** كل أنواع العناصر، ومقابض منتصف الحافة، والفتحات.

### العائلات البارامترية ومخطط العائلة

افتح نافذة **Family Sketch** لترسم مقطعًا وتحوّله إلى عائلة:

- ارسم **مستطيلًا** أو **دائرة** أو **مضلعًا**.
- استخدم **Next: draw hole** لعمل ثقوب في المقطع.
- فعّل **Size as parameters** لجعل عرض المستطيل وطوله (أو نصف قطر الدائرة) معاملات قابلة للتعديل.
- طبّق لإنشاء العائلة، فتظهر في متصفح العائلات (Family Browser).

التفاصيل في `docs/FAMILY-SKETCH.md`. **لم يُختبر:** وضع عائلة مرسومة في النموذج ثلاثي الأبعاد وتعديل معاملاتها بعد ذلك.

## 8. التنسيق والجودة

- **الدمج (Federation):** حمّل عدة نماذج وحاذِها في مساحة Federation.
- **كشف التعارضات:** **F5** يشغّل اختبار التعارض؛ **Ctrl+Shift+C** يبدّل نافذة مراجعة التعارضات.
- **المشكلات وBCF:** أنشئ مشكلات من عرض واستورد/صدّر ملفات BCF.
- **IDS والتحقق:** افحص النماذج مقابل متطلبات المعلومات IDS وقواعد التحقق المدمجة؛ واستخدم Model Health للتشخيص.

هذه الميزات مغطاة باختبارات الوحدة لكنها لم تُشغَّل في اختبارات المتصفح الموصوفة هنا.

## 9. التوثيق: العروض واللوحات وPDF

- أنشئ مساقط ومقاطع وواجهات ومساقط أسقف.
- أضف أبعادًا ووسومًا وملاحظات ومفاتيح وسلاسل أبعاد تلقائية.
- رتّب العروض على **لوحات (sheets)** بإطارات وعناوين وتنقيحات ثم **صدّر PDF**.
- قوالب العروض ومرشّحاتها تطبّق المعايير الرسومية بانتظام.

## 10. تصدير النموذج والعروض إلى CAD

اختر **File ← Views ← CAD (DWG / DXF)…**.

- **عروض ثنائية الأبعاد إلى CAD:** اختر عرضًا أو أكثر وصيغة DXF أو DWG ثم صدّر. تُسلَّم العروض المتعددة في ملف zip.
- **النموذج ثلاثي الأبعاد إلى DXF أو DWG:** يمكن لنافذة التصدير كتابة النموذج المنشأ ونماذج IFC المحمّلة كأوجه ثلاثية الأبعاد في DXF أو DWG. اختر الصيغة في مربع *3D model*. بعد تصدير DWG تذكر الرسالة عدد الكيانات التي وجدها التطبيق عند إعادة قراءة الملف.
- **العرض ثلاثي الأبعاد الحالي كخطوط ثنائية الأبعاد:** يرسم الخيار *Current 3D view → 2D lines* النموذج كما تراه الآن (بكاميرتك) كخطوط مسطحة مع إزالة الحواف المخفية، بصيغة DXF أو DWG. اضبط العرض أولًا (مثلًا العرض الأمامي ثم اضغط F). العروض المنظورية تُرسم بمقياس عند مسافة النموذج، فاستخدم عرضًا متعامدًا عندما تحتاج مقياسًا حقيقيًا. العناصر المكوَّنة من عدة قطع متلاصقة تُظهر خطوط التقاء بين القطع.
- المحاور: المحور الرأسي في التطبيق هو Y؛ ومخرجات CAD يكون الرأسي فيها Z.

**تم التحقق:** تُنشأ ملفات DXF وتُنزَّل في متصفح حقيقي؛ جدار IFC يُصدَّر على الطبقة المتوقعة بأبعاد نحو 5 م × 3 م؛ وكاتب DWG يعمل ذهابًا وإيابًا في محرك CAD في اختبار آلي.

**لم يُتحقق منه:** فتح الملفات المصدّرة في AutoCAD أو BricsCAD أو Revit؛ تصدير نماذج IFC الكبيرة جدًا؛ التصدير ثلاثي الأبعاد الكبير جدًا إلى DWG؛ وتصدير الخطوط الثنائية فُحص على جدار IFC واحد ولم تُقارن نتيجته بإزالة الخطوط المخفية في برنامج CAD.

### PDF إلى DWG (CAD ثنائي الأبعاد)

في محرر CAD الثنائي اختر **PDF → DWG…** (قائمة File أو الشريط) أو اكتب PDFTODWG. ملفات PDF الاتجاهية (خطوط وأقواس ونصوص من تصديرات CAD) تتحول إلى هندسة DWG قابلة للتعديل.

**اختُبر في متصفح حقيقي:** ملف PDF اتجاهي يتحول إلى ملف DWG حقيقي. **لم يُختبر:** ملفات PDF الممسوحة ضوئيًا (فهي صور لا خطوط)، وملفات PDF متعددة الصفحات في المتصفح، وفتح النتيجة في AutoCAD أو BricsCAD.

### الرابط المباشر مع IFC (Live IFC link)

اختر **File ← Live IFC link…** لكتابة عناصرك القابلة للتعديل (Native Twin) في ملف IFC تختاره وإبقائه محدّثًا أثناء التعديل. تُسجَّل التغييرات في سجل التغييرات، وتظهر رسالة تعارض إذا تغيّر الملف خارج التطبيق. يحتاج متصفحًا مبنيًا على Chromium (Chrome أو Edge) لأنه يستخدم File System Access API. التفاصيل في `docs/LIVE-IFC-LINK.md`.

**اختُبر في متصفح حقيقي** بمنتقي ملفات بديل؛ ملف IFC الناتج يُعاد تحميله بنجاح. **لم يُختبر:** منتقي الملفات والقرص الحقيقيان، والتبادل مع Revit، وعارضات IFC الأخرى.

## 11. مرجع سريع

|---|---|

## 12. استكشاف الأخطاء

| المشكلة | ما تجربه |
|---|---|
| الدوران بطيء أو متقطع | فعّل **View: Smooth navigation**. أخفِ الفئات غير اللازمة. أغلق علامات تبويب المتصفح الثقيلة الأخرى. |
| جزء من النموذج مفقود بعد استخدام صندوق القطع | اضغط **Ctrl+B** لإيقافه أو استخدم **Reset** من Ctrl+P. |
| لا يدور العرض ثلاثي الأبعاد | اضغط **Esc**. إذا كانت أداة أو وضع المشي نشطًا فإن Esc يخرج منه. |
| يبدأ وضع المشي بالنظر في اتجاه خاطئ | اخرج بـ Esc، واضبط العرض المطلوب، ثم اضغط Ctrl+W من جديد. انتظر ثانيتين بعد تحميل نموذج لأن العرض يتحرك ليلائم النموذج. |
| اختصار لا يفعل شيئًا | انقر العرض ثلاثي الأبعاد أولًا ليحصل على التركيز. عندما تكون لوحة رسم نشطة فإن محرر الرسم يملك بعض الاختصارات. |
| ملف لا يُفتح | راجع `docs/COMPATIBILITY.md`. بعض الصيغ (مثل LAZ وE57 وRCP للسحب النقطية) لا يمكن قراءتها في المتصفح؛ حوّلها أولًا. |
