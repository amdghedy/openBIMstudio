# Documentation (views & Sheets)

## View Templates
View Templates allow you to control the Visibility/Graphics (VG) of a view. 

### How to apply a Template:
1. Open the Views Panel.
2. Select a view (e.g., Level 1 Plan).
3. In the template dropdown, select an existing template or click "VG" to open the dialog.
4. Change the category visibility, detail level, or model display (Wireframe, Shaded).
5. Click "Save as Template" to reuse this style across other views.

## Sheets
Drag and drop your Plans, Sections, and Elevations onto an A1 or A3 Sheet to create professional documentation sets.
