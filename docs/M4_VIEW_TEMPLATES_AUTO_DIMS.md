# M4 — View Templates + Visibility/Graphics + Auto-Dimensions

Revit-parity package for **openBIMstudio**.

## What this adds

| Capability | Revit equivalent | Module |
|------------|------------------|--------|
| View Templates (create / apply / lock-style) | View Templates | `modules/view-templates/` |
| Visibility/Graphics dialog | VG (VV / VG) | `vg-dialog.ts` |
| Category visibility, halftone, transparent | Model + Annotation categories | types + store |
| View filters (basic rules) | View Filters | filters tab |
| Detail level + model display | View properties | Options tab |
| Sync into existing `__obsVisibility` | Temporary Hide-Isolate + category overrides | `syncToVisibilityFilter` |
| Auto dimension plan (X/Y chains) | Annotate → Aligned / overall + intermediates | `modules/auto-dimensions/` |
| Temporary → permanent promote | Promote temporary dimensions | engine |
| Screen-space dimension overlay | Dimension strings in views | SVG overlay |
| Command palette + Command Center + toolbar | Ribbon / QAT | boot inject |

## Install

From the **openBIMstudio project root**:

```bash
# Copy package next to the repo (or unzip)
# Then:
node path/to/revit-parity-m4/scripts/install-m4.mjs .

# Dry-run first (optional):
node path/to/revit-parity-m4/scripts/install-m4.mjs . --dry-run

npm run typecheck
npm run dev
```

The installer:

1. Copies `src/modules/view-templates/**`, `src/modules/auto-dimensions/**`, `src/features/m4-view-dims-boot.ts`
2. Patches `src/critical-gaps-boot.ts` to call `setupM4ViewDims()` (idempotent)

`main.ts` already imports `./critical-gaps-boot` — no further entry change.

## Seeded templates

On first run the store seeds:

- **Architectural Plan** — MEP/structure categories off by default  
- **Structural Plan** — architecture halftone, MEP off  
- **Coordination** — all disciplines visible  
- **Presentation 3D** — annotations off, realistic, fine  

Templates and view bindings persist in `localStorage` (`obs.viewTemplates.v1`, `obs.viewTemplateBindings.v1`).

## Events

- `obs:vg-changed` — `{ viewId, templateId }` after Apply / OK  

Listen to refresh 2D generators or Three.js materials.

## Integration with existing visibility-filter

`viewTemplatesStore.syncToVisibilityFilter(viewId)` pushes effective category overrides into `__obsVisibility.setCategoryOverride` when present. Temporary hide/isolate continues to work as before.

## Auto-dimension behaviour

1. Collects wall/column/grid reference edges from `ctx.model.elements` / grids (best-effort).  
2. Clusters coincident faces (~20 mm tolerance).  
3. Emits **overall** + **intermediate chain** strings (EQ when equal).  
4. Renders SVG overlay in the viewport (screen-space).  
5. Source `auto` can be cleared without removing user dimensions.

For best results, ensure elements expose `category`, `id`, and either `outline`/`footprint` or a world bounding box / mesh.

## Limitations (honest)

- View-template “lock” prevents local VG edits in the store sense; it does not yet freeze the entire view object graph.  
- Filters are stored and shown; evaluation against element parameters is left to the host (hook via `obs:vg-changed`).  
- Auto-dim geometry uses bbox/outline heuristics — complex curtain walls / free-form may need richer edge export from the geometry pipeline.  
- Angular / radial / arc-length kinds are typed but not yet generated by the plan auto-runner.  
- Overlay is screen-space (good for 3D + plan); sheet/PDF dimension baking is a follow-up (M3 sheet pipeline).  
- Existing dark Command Center styling is preserved; new VG + Dim panels use the required **Fluent light** tokens.

## Verification checklist

1. `npm run typecheck` — clean.  
2. Console: `[m4-view-dims-boot] View Templates + Auto-Dimensions wired`.  
3. Ctrl+Shift+V → dialog opens, category toggles work, Apply updates `__obsVisibility` (if loaded).  
4. Save as Template → appears in dropdown after reload.  
5. Ctrl+Shift+D → panel opens; **Auto Plan (X + Y)** creates overlay strings when model elements exist.  
6. Command Center shows **View · Annotate (M4)** section within ~1s of open.
